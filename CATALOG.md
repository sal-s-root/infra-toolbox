# Check catalog

| Check | Area | Scope | Limitations |
|---|---|---|---|
| linux-permission-inspector | linux | Decode Unix permission bits and flag world-writable files. | Decodes supplied metadata; does not inspect ACLs, ownership, or effective permissions. |
| disk-capacity-planner | linux | Calculate filesystem capacity headroom before a maintenance change. | Uses a static snapshot; filesystem reserved blocks and growth rates are not collected. |
| memory-pressure-checker | linux | Summarize a Linux meminfo snapshot without confusing cached memory with unavailable memory. | Accepts Linux meminfo text; pressure percentage is a capacity indicator, not Linux PSI. |
| process-snapshot-sorter | linux | Rank a supplied process snapshot by CPU consumption. | Does not sample live processes; CPU percentages depend on the upstream collection interval. |
| inode-usage-checker | linux | Identify inode exhaustion separately from byte capacity. | Filesystems without a fixed inode capacity require different interpretation. |
| mount-option-auditor | linux | Compare mount options with an explicit expected hardening policy. | Policy is supplied per mount; applying noexec or other flags can break applications and is not performed. |
| path-entry-auditor | linux | Detect PATH entries that depend on the working directory. | Does not check directory ownership, symlinks, or write permissions. |
| system-load-analyzer | linux | Normalize load averages against a supplied CPU count. | Linux load includes uninterruptible tasks; this is not a CPU utilization measurement. |
| uid-collision-detector | linux | Find account names sharing a numeric UID in passwd-format data. | Some shared UIDs are intentional; review identity sources and policy before changing accounts. |
| file-integrity-manifest | linux | Generate deterministic SHA-256 hashes for supplied text file contents. | UTF-8 text input only; hashes prove content equality, not authenticity or trusted provenance. |
| log-level-counter | linux | Count explicit severity tokens in text logs. | Matches the first uppercase token; structured logging avoids ambiguous text classification. |
| cron-field-validator | linux | Validate a deliberately restricted five-field cron schedule. | Does not support ranges, steps, lists, macros, timezone semantics, or calendar feasibility. |
| directory-size-summary | linux | Group collected file sizes by top-level relative directory. | Uses a supplied file inventory; sparse allocation, hard links, and compression are not modeled. |
| environment-variable-auditor | linux | Check required environment variable names without printing secret values. | Input may contain secrets; use protected files and avoid recording request bodies. |
| service-port-inventory | linux | Find services that claim the same transport protocol and port. | Binding conflicts also depend on addresses, namespaces, and reuse settings; these are not modeled. |
| cidr-overlap-checker | networking | Find overlapping IP networks in a proposed address inventory. | Compares CIDRs only; does not read routes, peering relationships, or cloud accounts. |
| subnet-capacity-calculator | networking | Calculate IPv4 address capacity with explicit provider reservations. | Reservation count is user supplied; point-to-point and provider-specific rules differ. |
| dns-record-linter | networking | Validate a small DNS inventory for address family and TTL consistency. | Does not resolve DNS or validate CNAME coexistence, DNSSEC, TXT data, or authority. |
| http-access-log-summary | networking | Summarize structured HTTP request records by status class and route. | Consumes normalized records, not raw combined-log-format lines; route cardinality must be controlled. |
| tls-expiry-planner | networking | Calculate a certificate renewal deadline relative to an explicit evaluation time. | Uses supplied expiry metadata; does not perform a TLS handshake or inspect certificate trust. |
| latency-percentile-calculator | networking | Compute nearest-rank latency percentiles from observed samples. | Nearest-rank estimates from small samples are coarse; do not average these percentiles across hosts. |
| tcp-retry-budget | networking | Estimate the maximum configured connection-attempt time including exponential retry delays. | A model rather than a network probe; excludes DNS, scheduling, jitter, and application processing. |
| route-longest-prefix | networking | Select the most specific matching route for an IP destination. | Does not model metrics, policy routing, equal-cost multipath, or interface state. |
| nginx-upstream-checker | networking | Review a normalized upstream pool for duplicate endpoints and traffic weights. | Reads normalized JSON, not nginx syntax; failover, max_fails, and passive health behavior are outside scope. |
| ip-allowlist-evaluator | networking | Evaluate whether supplied client addresses belong to an explicit CIDR allowlist. | An offline membership check; it does not configure a firewall or establish client identity. |
| port-range-merger | networking | Collapse overlapping or adjacent port ranges into a minimal equivalent list. | Merge only ranges with the same protocol, direction, and policy action. |
| url-health-manifest | networking | Review health-check URLs for schemes, embedded credentials, and duplicates. | Does not make requests or resolve hosts. A syntactically valid URL is not necessarily reachable or trusted. |
| json-log-filter | networking | Filter JSON log records with exact field matching and a bounded result count. | In-memory exact matching only; input and output logs may contain sensitive information. |
| syslog-severity-summary | networking | Decode syslog priority numbers into facility and severity counts. | Uses numeric syslog priority values; does not parse timestamps, hostnames, or transport framing. |
| network-throughput-estimator | networking | Calculate observed bit rate from cumulative byte counters. | Assumes one monotonic counter without wraparound; reported rate depends on sampling accuracy. |
| http-status-budget | networking | Calculate a request failure ratio using an explicit server-error classification. | Counts only 5xx as failures; service-specific availability may classify timeouts and some 4xx differently. |
| config-drift-detector | configuration | Compare desired and observed configuration values without modifying hosts. | Compares top-level keys; values may contain secrets, so review input and output handling. |
| backup-retention-planner | configuration | Select dated backups to retain under a count-based policy. | Produces a plan only; backup chains, legal retention, immutability, and restore tests require separate checks. |
| rotation-size-planner | configuration | Estimate storage consumed by rotated logs and an active file. | Assumes equally sized rotations; compression ratios and log growth vary. No files are rotated or removed. |
| ssh-policy-auditor | configuration | Check selected sshd directives against an explicit expected policy. | A restricted text review; use sshd -T with connection criteria for effective production settings. |
| sudo-policy-linter | configuration | Flag broad passwordless sudo rules for manual review. | Not a sudoers parser or security proof. Validate syntax with visudo and review aliases and includes separately. |
| ansible-inventory-auditor | configuration | Find hosts without an owner group in a normalized inventory. | Uses a flat JSON projection; Ansible child groups, patterns, and variable precedence are not evaluated. |
| systemd-unit-linter | configuration | Review selected service-unit settings for predictable operation. | Restricted INI subset only; repeated directives and systemd override semantics require systemd-analyze verify. |
| package-pin-auditor | configuration | Find package requirements missing an exact version in a normalized package list. | Checks normalized version strings, not package-manager resolution or vulnerability status. |
| secret-redaction-filter | configuration | Redact values beneath explicitly sensitive JSON key names. | Exact key matching only; secrets embedded in free text or unexpected fields will remain. |
| configuration-overlay-merge | configuration | Merge configuration objects with explicit recursive object and replacement-list behavior. | Lists and nulls replace existing values; no schema validation, variable expansion, or secret resolution is performed. |
| backup-manifest-verifier | configuration | Compare an expected checksum manifest against observed checksum metadata. | Compares supplied checksum strings; it does not independently read backups or validate the trusted manifest. |
| maintenance-window-planner | configuration | Find conflicting UTC maintenance intervals. | Treats intervals as half-open; does not model recurrence, business calendars, or service dependency exceptions. |
| certificate-inventory-reporter | configuration | Group certificate inventory entries by owner and identify missing ownership. | Ownership reporting only; issuance, revocation, trust chains, and expiry verification are separate tasks. |
| least-privilege-file-auditor | configuration | Review file modes against an expected permission ceiling. | Does not evaluate ACLs, capabilities, mount policies, ownership, or required minimum permissions. |
| change-plan-risk-checker | configuration | Flag destructive changes to stateful resources for review. | A review aid rather than an approval system; statefulness must be identified accurately by the caller. |
| ansible-task-tag-auditor | configuration | Review normalized Ansible task metadata for operational tags. | Accepts expanded task metadata; does not resolve inherited tags, includes, roles, or special Ansible tags. |
| dockerfile-policy-checker | delivery | Review a Dockerfile for an explicit runtime user, health check, and base image tag. | A line-oriented review only; it does not resolve build stages, ARGs, inherited health checks, or Dockerfile continuations. |
| compose-port-auditor | delivery | Find Compose published ports exposed on wildcard addresses. | Uses expanded Compose JSON port objects; host firewall policy and Docker networking still affect reachability. |
| container-resource-planner | delivery | Compare aggregate container reservations with a host capacity budget. | A sum of supplied reservations; ignores host overhead, noisy neighbors, burst capacity, and placement constraints. |
| image-tag-policy-checker | delivery | Distinguish digest-pinned images from mutable tags. | Digest syntax does not prove an image exists, is signed, or is free from vulnerabilities. |
| healthcheck-timing-calculator | delivery | Model failure detection for a stated fixed-start-interval health-check schedule. | An idealized fixed-start schedule; Docker and orchestrators can schedule checks differently, so measure real detection time. |
| ci-job-dependency-checker | delivery | Topologically group CI jobs and detect unknown dependencies or cycles. | Models static dependencies only; conditions, matrices, reusable workflows, and concurrency controls are not evaluated. |
| artifact-checksum-verifier | delivery | Verify UTF-8 artifact content against an expected SHA-256 digest. | Text artifacts only; trust in the expected digest must come from a separate authenticated source. |
| build-context-auditor | delivery | Identify potentially sensitive files in a supplied container build-context inventory. | Uses simple fnmatch rules, not full dockerignore semantics; file content and embedded secrets are not scanned. |
| environment-parity-checker | delivery | Compare selected configuration keys between two deployment environments. | Does not print values; intentionally different environment settings should be excluded explicitly. |
| deployment-wave-planner | delivery | Split a defined deployment order into bounded rollout waves. | Uses caller-supplied order; it does not infer dependency safety or perform deployments. |
| container-log-normalizer | delivery | Normalize selected structured container log fields into a stable record shape. | Consumes JSON records; multiline joining, trace correlation, redaction, and timestamp inference are outside scope. |
| image-layer-budget | delivery | Review image-layer sizes against a supplied storage budget. | Compressed and unpacked sizes differ; shared layers and registry deduplication are not modeled. |
| registry-reference-parser | delivery | Split an explicit registry image reference into repository, tag, and digest fields. | Parses a restricted reference shape; it does not validate the complete OCI name grammar or contact a registry. |
| ci-matrix-expander | delivery | Expand a bounded Cartesian test matrix from named dimensions. | Does not evaluate include/exclude expressions or CI provider limits beyond the local combination cap. |
| release-manifest-validator | delivery | Check a normalized release manifest for unique services and immutable image digests. | Checks manifest structure only; digest existence, signatures, compatibility, and deployment approval are separate concerns. |
| readiness-gate-evaluator | delivery | Evaluate named readiness checks against success and latency criteria. | Evaluates supplied observations; no probes are executed and readiness is not an uptime guarantee. |
| terraform-plan-risk-auditor | cloud | Summarize destructive actions from Terraform plan JSON. | Consumes plan JSON; does not evaluate unknown values, sensitive data, policy exceptions, or apply resources. |
| aws-security-group-auditor | cloud | Flag Internet-wide rules exposing SSH, RDP, or all IP protocols. | Static ingress review; routing, NACLs, IPv6 prefix lists, security group references, and reachability are not evaluated. |
| cloud-tag-compliance | cloud | Find missing ownership and cost allocation tags in resource inventory. | Uses normalized inventory; tagging support, inherited tags, and policy exceptions vary by resource type. |
| cloud-resource-cost-estimator | cloud | Estimate usage-based cost using rates supplied by the caller. | No live prices or billing guarantees; excludes taxes, discounts, transfer, storage, and other charges unless supplied explicitly. |
| vpc-address-planner | cloud | Allocate a bounded number of equal-size subnets from a parent IPv4 network. | Does not consult existing allocations or provider constraints; validate against the organization IPAM system. |
| iam-wildcard-auditor | cloud | Identify wildcard Allow statements requiring an IAM policy review. | Not an IAM authorization evaluator; conditions, Deny statements, SCPs, permission boundaries, and resource policies can alter effective access. |
| s3-public-access-checker | cloud | Review the four S3 Public Access Block settings in supplied bucket metadata. | Reports settings only, not effective public access. Account-level blocks, ACLs, policies, and access points require separate inspection. |
| terraform-output-redactor | cloud | Redact outputs marked sensitive in Terraform output JSON. | Relies on correct sensitive metadata; misclassified secrets remain visible and input must be protected. |
| cloud-quota-headroom | cloud | Calculate quota usage and flag insufficient capacity for planned additions. | Uses a static regional/account snapshot; quota increases, resource release timing, and service limits are not requested. |
| availability-zone-distributor | cloud | Distribute a desired replica count evenly across supplied zones. | A desired distribution, not a placement scheduler; ignores zonal capacity, stateful topology, and disruption budgets. |
| cloud-budget-forecast | cloud | Extrapolate period spend using elapsed-day average cost. | Straight-line projection only; does not model credits, seasonality, billing delay, or commitments. |
| ebs-snapshot-retention | cloud | Plan count-based snapshot retention independently for each volume. | No AWS calls or deletions; AMI dependencies, incomplete snapshots, backup policies, and compliance locks need independent review. |
| terraform-dependency-graph | cloud | Build reverse dependencies from a normalized resource dependency inventory. | Consumes a normalized graph, not HCL or Terraform graph output; implicit references and cycles require other checks. |
| cloud-idle-resource-finder | cloud | Find resource observations below a caller-defined utilization threshold. | Low CPU alone does not prove a resource is unused. Check traffic, memory, duty cycle, ownership, and recovery roles. |
| network-egress-cost-planner | cloud | Estimate transfer cost from explicitly priced network flows. | Rates are example inputs, not live provider prices. Tiers, free allowances, direction, and region affect billing. |
| slo-error-budget-calculator | reliability | Calculate a request-based error budget and remaining allowance. | Assumes valid events and good/bad classification already defined; fractional budgets are expected with ratio objectives. |
| burn-rate-alert-evaluator | reliability | Evaluate paired error-ratio windows against one burn-rate threshold. | Requires pre-aggregated windows; no traffic floor, missing-data policy, paging integration, or recording-rule evaluation is implemented. |
| incident-timeline-checker | reliability | Validate incident event ordering and summarize observed elapsed time. | Examples are exercises, not production incident claims. Event span alone is not necessarily customer-impact duration. |
| alert-deduplication-tool | reliability | Group alerts by a caller-selected identity label set. | An offline grouping exercise; production alert grouping must preserve routing boundaries and incident semantics. |
| runbook-coverage-auditor | reliability | Find services missing operational ownership or a runbook URL. | Presence checks only; does not validate URL reachability, ownership currency, or runbook effectiveness. |
| oncall-handoff-builder | reliability | Assemble an open-item handoff from normalized operational records. | Builds a draft from provided facts only; it does not send messages, contact on-call staff, or invent incidents. |
| recovery-time-analyzer | reliability | Compare recorded recovery drill durations with a stated recovery-time target. | Uses completed drill observations; sample results do not prove a production RTO or include data-loss measurement. |
| capacity-forecast-tool | reliability | Extrapolate resource exhaustion from two dated usage observations. | A two-point linear projection with no confidence interval; validate trends and planned changes before buying capacity. |
| prometheus-label-cardinality | reliability | Estimate series cardinality from independent label value inventories. | Assumes a complete Cartesian product and one series per combination; histograms and correlated labels change the estimate. |
| prometheus-textfile-validator | reliability | Validate a deliberately small unlabeled Prometheus textfile subset. | Supports unlabeled finite numeric samples only; labels, timestamps, histograms, exemplars, and special values are rejected. |
| prometheus-alert-rule-linter | reliability | Review normalized alert rules for names, expressions, ownership, and a hold duration. | Does not parse PromQL or replace promtool check rules. Compound and zero durations are intentionally outside this subset. |
| retry-storm-simulator | reliability | Model worst-case request amplification when every client exhausts retries. | A worst-case count model; no requests are sent. Backoff, jitter, partial success, and time overlap are not simulated. |
| chaos-experiment-planner | reliability | Review a lab failure-exercise proposal for blast-radius and stop-condition metadata. | Metadata review only; a passing result is not authorization or proof of safety. No fault is injected. |
| service-dependency-impact | reliability | Find services transitively dependent on a failed component. | Graph reachability indicates potential impact; caches, redundancy, fallbacks, and partial degradation require runtime evidence. |
| postmortem-action-tracker | reliability | Identify overdue open follow-up actions relative to an explicit date. | Example actions are exercises. The tool does not create issues, assign owners, or verify completion evidence. |
